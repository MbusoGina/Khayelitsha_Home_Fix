## Project Overview:
Khayelitsha HomeFix is a Cape Town home-maintenance business used for the WEDE5020 website project.
The website provides information about services and allows visitors to submit enquiries.

## Website Goals and Objectives:
- Establish an online presence.
- Explain services clearly.
- Generate service and quotation enquiries.
- Make contact information easy to find.
- Provide a responsive and accessible user experience.
